# Dependencias de la Raspberry Pi 4B.
#
# EL SISTEMA TIENE QUE SER RASPBERRY PI OS DE 64 BITS. El modelo .eim es un
# ejecutable AArch64 y no corre en 32 bits; además, el marcador de plataforma
# de edge_impulse_linux (más abajo) hace que pip lo salte EN SILENCIO en un
# sistema de 32 bits. Comprobalo con `uname -m`: tiene que decir aarch64.
#
# Instalación:
#
#   sudo apt install python3-opencv python3-numpy python3-serial
#   sudo usermod -aG dialout $USER      # para abrir /dev/ttyACM* y /dev/ttyUSB*
#
# Se prefiere apt para OpenCV y NumPy: los paquetes del sistema vienen
# compilados con las optimizaciones NEON del procesador ARM. Instalarlos con
# pip descarga ruedas genéricas que corren notablemente más lento.

numpy>=1.24
opencv-python>=4.8        # o python3-opencv desde apt (preferido en la Pi)
pyserial>=3.5

# Detector de banderas entrenado en Edge Impulse. Es OBLIGATORIO en la Pi:
# sin él, run_rover.py no arranca. El entrenamiento se hace fuera del repo,
# en Edge Impulse Studio; acá solo corre el .eim ya exportado
# (models/athena_ei_banderas.eim).
#
# En la Pi hace falta instalar antes estas dependencias de sistema:
#
#   sudo apt install libatlas-base-dev libportaudio0 libportaudio2 \
#       libportaudiocpp0 portaudio19-dev
#   pip install --break-system-packages edge_impulse_linux
edge_impulse_linux ; platform_machine == "aarch64"
